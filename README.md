# ВидеоЛоопер (Kivy/Python) — видео-лоопер в киоск-режиме

Аналог SureVideo: при включении устройства открывается плеер на весь экран
и по очереди проигрывает все видео из выбранной папки, в бесконечном цикле.

## Управление (всё внутри приложения)

- **5 быстрых касаний экрана** (успеть за ~2 секунды) → **ввод PIN-кода**.
- PIN по умолчанию: **1234** (меняется в «Настройки» → «Сменить PIN-код»).
- После ввода PIN открывается **меню**:
  - **Настройки** — выбор папки с видео (проводник), перемешивание роликов,
    смена PIN;
  - **Выйти из приложения**;
  - **Продолжить показ**.
- Все настройки сохраняются между перезапусками (файл
  `videolooper_settings.json` в папке приложения).

## Как собрать APK (всё делается в облаке, на вашем ПК ничего не ставится)

1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий
   (кнопка «New», имя например `videolooper`, публичный).
2. Загрузите в репозиторий файлы (кнопка «uploading an existing file»,
   можно перетащить всё сразу, папку `.github` — целиком):
   - `main.py`
   - `buildozer.spec`
   - `.github/workflows/build.yml`
3. Откройте вкладку **Actions** → выберите workflow **Build APK** →
   **Run workflow**. (Запустится и автоматически, если файлы загружались
   push-ем в ветку main.)
4. Подождите 20–60 минут (первая сборка самая долгая). Затем откройте
   завершённый запуск → раздел **Artifacts** → скачайте `videolooper-apk`
   — внутри ZIP будет файл вида
   `videolooper-0.1-arm64-v8a_armeabi-v7a-debug.apk`.
5. Перенесите APK на плату (флешкой или скачав в браузере) и установите,
   разрешив установку из неизвестных источников.

## Использование на плате HD-133M

1. Включите в настройках платы автозапуск последнего приложения.
2. Один раз запустите «ВидеоЛоопер» вручную, разрешите доступ к файлам
   и через меню (5 касаний → PIN 1234) выберите папку с видео.
3. Перезагрузите плату — плеер откроется сам и начнёт с первого видео.

## Рекомендации по видео

- Формат: MP4 с кодеком H.264 (самый совместимый).
- Разрешение: 1920×1080. 4K на слабых платах может тормозить —
  воспроизведение идёт через программный декодер ffpyplayer.
- Экран не гаснет (FLAG_KEEP_SCREEN_ON), системные панели скрыты.
